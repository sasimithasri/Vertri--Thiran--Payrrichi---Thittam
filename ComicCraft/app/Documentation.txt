COMICCRAFT - AI COMIC STORY CREATOR
Project Documentation 2025-2026

1. ABSTRACT:
ComicCraft is AI powered web app that generates 5-panel comic from user prompt. User gives story, character, setting, tone. Backend creates 5 panels and AI images using Pollinations.ai.

2. TECH STACK:
Backend - Python, FastAPI, Uvicorn
Frontend - HTML, Jinja2
AI Image - Pollinations.ai free API
IDE - VS Code

3. HOW TO RUN:
pip install fastapi uvicorn jinja2 requests
python -m uvicorn app.main:app --port 8000
Open http://127.0.0.1:8000
Enter story -> Generate Comic -> 5 panels ready!

4. MY OUTPUT PROOF:

Full comic with 5 panels generated
